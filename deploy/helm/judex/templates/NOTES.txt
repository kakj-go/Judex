This build serves the API foundation and production frontend shell.
Business authentication, persistence and Agent execution are not implemented.
GET /api/v1/system reports actual capabilities. Probes cover HTTP only.

PostgreSQL/S3 PVCs and generated Secrets are retained on uninstall.
The {{ .Release.Namespace }}-sandboxes namespace is retained as well.
