# 项目客厅功能承载验证

Q021整体业务依据已获确认，Q085明确分支用户侧自由组织。本轮Demo已调整为自由分支关联、AI进度展示与明确事件联动；真实代码工作仍在成员本地完成。

| 能力 | 当前落点与验证 |
| --- | --- |
| 项目 | 首页创建后进入客厅，默认岗位由主管承接 |
| 计划关联 | 计划草案可带任意仓库/分支，审批只建立内部计划任务和关联；已有计划可维护关联 |
| 任务关联 | 每任务独立、多仓、多分支、跨对象复用；无命名或来源门槛 |
| 修复关联 | Bug卡片独立关联修复分支，不自动继承其他对象的关联 |
| AI进度 | 只读观察的演示输入驱动估算，显示依据/时间；不会替人完成或撤销人工状态 |
| 开发/测试 | 责任人明确开发完成，测试结果直接验收；未交测试先留证据，不跳过开发交接 |
| Bug | 授权测试提交即联动多任务与计划，支持协调机器人及各任务复测记录 |
| 正式审批 | 计划保留发送/接收确认、真人去重、版本和历史；普通Bug/测试不再套入额外审批 |
| 发布台账 | 实际结果与内部状态分开，失败/进行中不变成成功，工作未结束也可回报 |
| 资料目录 | 上报自动生成文件，按计划/机器人组织；支持1MB文本/图片上传、时间和原作者保留 |
| 角色交接 | 主管兜底、同岗多个机器人、岗位知识继承，个人偏好与历史真人不改写 |

本轮生产构建、24项状态测试和8条Edge E2E全部通过；已检查中英深浅桌面及无横向溢出，源文件均小于2000行。没有执行真实Git、模型或部署操作。

目录和只读观察目前均为浏览器演示；真实Git/CLI、SQLite、OpenSandbox及其他未覆盖能力见[Demo范围](./Demo.md)。已确认业务规则不等于全部生产实现完成。
