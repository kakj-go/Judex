# 13. 工程骨架与实现状态

2026-09-25 按用户要求生成正式工程。本文件记录实现边界，不修改既有产品决定。

## 已落地

- `cmd/judex-server` + `internal`：Go / Gin 模块化单体，配置校验、结构化日志、请求 ID、统一错误、探针、优雅退出、前端托管。
- `cmd/judex`：查询真实服务状态。`cmd/judex-agent`：入口和接口预留，未实现时明确退出，不在 API 宿主机执行 bash。
- `web`：React / TypeScript / Vite，HeroUI、Tailwind、Zustand 偏好、TanStack Query 数据层；迁入工作室全部交互，保留计划卡片树等路径。
- 预览与真实 API 分开。真实登录 / 注册表单调用 API，目前返回 501，不创建虚假用户，不把密码写 localStorage。
- `tests`：Go、前端规则、浏览器 E2E、Helm 矩阵、独立 K8s 冒烟入口。
- `deploy`：Docker 多阶段构建、Helm 开发 / 生产 values、内置 / 外部 PG 和 S3、固定版本 OpenSandbox。
- 根目录 Makefile、Apache-2.0 LICENSE / NOTICE、唯一 npm workspace 锁文件。
